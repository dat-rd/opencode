---

Tiện ích mở rộng Effect có thể phơi bày các phương thức và sự kiện trả về Effect và Stream có kiểu.

## Định nghĩa

Dùng `Rpc.define` cùng Effect Schema để định nghĩa RPC.

```ts title="src/rpc.ts"
import { Rpc } from "@opencode/plugin/rpc"
import { Schema } from "effect"

export const Acme = Rpc.define({
  id: "acme",
  methods: {
    search: {
      input: Schema.Struct({ query: Schema.String }),
      output: Schema.Struct({ text: Schema.String }),
      errors: {
        not_found: Schema.Struct({ query: Schema.String }),
      },
    },
  },
  events: {
    updated: {
      schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
    },
  },
})
```

### Kiểm tra

Effect Schema kiểm tra giá trị và suy luận kiểu TypeScript của chúng.

```ts
input: Schema.Struct({ query: Schema.String })
```

JSON Schema và Standard Schema cũng được hỗ trợ.

### Input và output

Dùng `input` cho đối số của phương thức và `output` cho giá trị trả về của nó. Hãy bỏ qua bất kỳ mục nào khi không có giá
trị.

```ts
search: {
  input: Schema.Struct({ query: Schema.String }),
  output: Schema.Struct({ text: Schema.String }),
}
```

### Lỗi

Thêm các lỗi dự kiến vào `errors`. Mỗi khoá trở thành `type` của lỗi.

```ts
errors: {
  not_found: Schema.Struct({ query: Schema.String }),
}
```

### Sự kiện

Thêm sự kiện vào map `events` cấp cao nhất. Dữ liệu sự kiện phải là một object.

```ts
events: {
  updated: {
    schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
  },
}
```

## Hiện thực

Đăng ký cách hiện thực từ Effect của tiện ích mở rộng:

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"
import { Acme } from "./rpc.js"

export default Plugin.define({
  id: "acme-effect-plugin",
  effect: (ctx) =>
    Effect.gen(function* () {
      const registration = yield* ctx.rpc.register(Acme, {
        search: ({ query }, context) =>
          findText(query).pipe(
            Effect.flatMap((text) =>
              text
                ? Effect.succeed({ text })
                : Effect.fail(context.error("not_found", "Result not found", { query })),
            ),
          ),
      })

      const acme = ctx.rpc(Acme)
      const result = yield* acme.search({ query: "hello" })

      yield* registration.events.emit("updated", { itemID: "item-1", text: result.text })
    }).pipe(Effect.orDie),
})
```

Map lỗi trở thành kiểu lỗi của Effect cho từng phương thức. Dùng `context.error(...)` để tạo một lỗi đã khai báo.

## Gọi

Sau khi RPC được đăng ký, bạn có thể gọi nó qua HTTP hoặc từ một tiện ích mở rộng khác.

### HTTP

Tạo client Effect, rồi tạo subclient cho RPC:

```ts
import { OpenCode } from "@opencode/client/effect"
import { Effect } from "effect"
import { FetchHttpClient } from "effect/http"
import { Acme } from "opencode-acme-plugin/rpc"

const program = Effect.gen(function* () {
  const client = yield* OpenCode.make({ baseUrl: "http://localhost:4096" })
  const acme = client.rpc(Acme)
  return yield* acme.search({ query: "hello" })
})

const result = await Effect.runPromise(program.pipe(Effect.provide(FetchHttpClient.layer)))
```

### Tiện ích mở rộng

Một tiện ích mở rộng Effect khác có thể tạo subclient cục bộ từ context của nó:

```ts
import { Effect } from "effect"

effect: (ctx) =>
  Effect.gen(function* () {
    const acme = ctx.rpc(Acme)
    const result = yield* acme.search({ query: "hello" })
    yield* Effect.logInfo(result.text)
  }).pipe(Effect.orDie)
```

### Đăng ký

Sự kiện RPC là các Stream. Hãy đăng ký theo tên sự kiện và chạy Stream trong một fiber có phạm vi:

```ts
import { Effect, Stream } from "effect"

const acme = ctx.rpc(Acme)

yield *
  acme.events.subscribe("updated").pipe(
    Stream.runForEach((event) => Effect.logInfo(event.data.text)),
    Effect.forkScoped,
  )
```

Đăng ký chỉ có hiệu lực trực tiếp và đóng lại khi việc consume Stream dừng.
