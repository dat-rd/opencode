title: "Effect"
---

`@opencode/plugin/effect` là phiên bản dựa trên Effect của API tiện ích mở rộng OpenCode. Các thao tác ngữ cảnh của
nó trả về Effect hoặc Stream, các callback trả về Effect, và vòng đời của tiện ích mở rộng được biểu diễn bằng
`Scope`.

OpenCode cung cấp `effect` (bao gồm cả các subpath `effect/*` được export) và `@opencode/plugin` ở runtime khi nạp
tiện ích mở rộng cùng các phụ thuộc `node_modules` của chúng. Hãy cài chúng dưới dạng peer/dev dependency cho việc
kiểm tra kiểu và kiểm thử cục bộ, thay vì đóng gói chúng vào tiện ích mở rộng của bạn.

```sh
bun add --peer @opencode/plugin effect
```

Export một tiện ích mở rộng Effect từ `.opencode/plugins/` để nó được nạp tự động.

```ts title=".opencode/plugins/concise/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "example",
  effect: (ctx) =>
    Effect.gen(function* () {
      const storage = ctx.storage
      yield* storage.set("loaded", true)
    }),
})
```

Các package đã xuất bản và thư mục tiện ích mở rộng nằm ngoài `.opencode/plugins/` dùng cùng cấu hình `plugins` với
các tiện ích mở rộng server khác.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "opencode-acme-effect-plugin",
    "opencode-acme-effect-plugin@1.2.0",
    "@acme/opencode-effect-plugin",
    "./plugins/local-effect",
    {
      "package": "@acme/opencode-effect-plugin",
      "options": { "agent": "reviewer", "strict": true },
    },
  ],
}
```

Xem [Cấu hình tiện ích mở rộng](/plugins) để biết về cách bật, phân giải package và thứ tự ưu tiên cấu hình.

```ts title="plugins/local-effect/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "local-effect",
  effect: (ctx) =>
    Effect.gen(function* () {
      yield* Effect.logInfo("Effect plugin loaded", { version: ctx.app.version })
    }),
})
```

## Vòng đời

Hàm `effect` chạy khi tiện ích mở rộng được nạp. Scope của nó đóng lại khi tiện ích mở rộng nạp lại hoặc được gỡ bỏ,
nên các đăng ký, fiber có phạm vi và finalizer được giải phóng cùng nhau.

```ts
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "lifecycle",
  effect: (ctx) =>
    Effect.gen(function* () {
      yield* Effect.logInfo("loaded", { version: ctx.app.version })
      yield* Effect.addFinalizer(() => Effect.logInfo("unloaded"))
    }),
})
```

Hãy dùng fiber có phạm vi cho công việc nền. Scope của tiện ích mở rộng sẽ ngắt fiber trong lúc dọn dẹp.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const storage = ctx.storage
    yield* Effect.repeat(
      storage.set("heartbeat", { time: Date.now() }),
      { schedule: Schedule.spaced("1 minute") },
    ).pipe(Effect.forkScoped)
  }),
```

### Ngữ cảnh

Ngữ cảnh cung cấp Effect client cho server OpenCode đã kết nối, cùng các transform, móc nối, lưu trữ, nạp lại và
tùy chọn chỉ dành cho tiện ích mở rộng. Nó không cung cấp các dịch vụ Core riêng tư của OpenCode.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const plugins = ctx.plugin
    const active = yield* plugins.list().pipe(Effect.orDie)
    yield* Effect.logInfo("active plugins", { count: active.data.length })
  }),
```

Định nghĩa tiện ích mở rộng và ngữ cảnh đầy đủ được khai báo như sau.

### Tùy chọn

Truyền tùy chọn bằng dạng đối tượng trong `opencode.json(c)`.

```jsonc title="opencode.jsonc"
{
  "plugins": [
    {
      "package": "./plugins/company-effect",
      "options": { "strict": true },
    },
  ],
}
```

Đọc tùy chọn từ `ctx.options`. Hãy thu hẹp các giá trị chưa biết trước khi sử dụng.

```ts title="plugins/company-effect/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "company",
  effect: (ctx) =>
    Effect.gen(function* () {
      const strict = ctx.options.strict === true
      yield* Effect.logInfo("company plugin configured", { strict })
    }),
})
```

## Transform

Transform sửa trạng thái đồng bộ thông qua một editor. OpenCode áp dụng các transform theo thứ tự đăng ký trong từng
domain. Các nguồn đóng góp nhà cung cấp và định nghĩa mô hình bất biến trước; các transform mô hình sau đó sửa các
ứng viên của những nhà cung cấp đang hoạt động. Yielding registration sẽ giữ nó trong scope của tiện ích mở rộng.

```ts title="plugins/models-effect/index.ts"
import { Model, Plugin, Provider } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "company.models",
  effect: (ctx) =>
    Effect.gen(function* () {
      const providerID = Provider.ID.make("acme")
      const models = [{ ...Model.Info.default(providerID, Model.ID.make("reasoner")), name: "Acme Reasoner" }]
      yield* ctx.provider.transform((editor) => {
        editor.add({
          info: {
            ...Provider.Info.empty(providerID),
            name: "Acme",
            activation: "enabled",
            package: "@opencode/ai/providers/openai-compatible",
            settings: { baseURL: "http://127.0.0.1:8000/v1" },
          },
          models,
        })
      })
    }),
})
```

Một transform mô hình có thể áp dụng chính sách trên toàn bộ tập ứng viên của các nhà cung cấp đang hoạt động.

```ts title="plugins/model-budget-effect/index.ts"
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.model.transform((editor) => {
      editor
        .list()
        .filter((model) => model.cost.some((tier) => tier.output > 20))
        .forEach((model) => {
          editor.remove(model.providerID, model.id)
        })
    })
  }),
```

Gọi `reload` khi trạng thái bên ngoài mà một transform sử dụng thay đổi. Ở đây, `loadFromSource()` trả về các mục
`{ info: Provider.Info, models: readonly Model.Info[] }`; việc nạp lại nhà cung cấp cũng vô hiệu hóa toàn bộ kết quả
mô hình.

```ts title="plugins/models-effect/index.ts"
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const source = { providers: yield* loadFromSource() }

    yield* provider.transform((editor) => {
      source.providers.forEach((provider) => editor.add(provider))
    })

    yield* Effect.repeat(
      Effect.gen(function* () {
        source.providers = yield* loadFromSource()
        yield* provider.reload()
      }),
      { schedule: Schedule.spaced("1 minute") },
    ).pipe(Effect.forkScoped)
  }),
```

## API

### Tác nhân

Đọc toàn bộ tác nhân hoặc lấy một tác nhân theo ID. Phản hồi của client chứa vị trí đã phân giải và dữ liệu schema.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const agent = ctx.agent
    const agents = yield* agent.list().pipe(Effect.orDie)
    const build = yield* agent.get({ agentID: Agent.ID.make("build") }).pipe(Effect.orDie)
    yield* Effect.logInfo("agents", { count: agents.data.length, build: build.data.name })
  }),
```

Biến đổi hoặc nạp lại tác nhân.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const agent = ctx.agent
    yield* agent.transform((editor) => {
      editor.default("build")
      editor.update("build", (item) => (item.description = "Builds features and fixes bugs"))
      editor.remove("legacy")
    })
    yield* agent.reload()
  }),
```

Schema: [`Agent.Info`](/api#schema-Agent.Info).

```ts
interface AgentEditor {
  list(): readonly Types.DeepMutable<Agent.Info>[]
  get(id: string): Types.DeepMutable<Agent.Info> | undefined
  default(id: string | undefined): void
  update(id: string, update: (agent: Types.DeepMutable<Agent.Info>) => void): void
  remove(id: string): void
}

interface AgentDomain extends AgentApi<unknown> {
  readonly transform: Transform<AgentEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### Nhà cung cấp

Đọc các nhà cung cấp khả dụng hoặc xem siêu dữ liệu của một nhà cung cấp theo ID.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const providers = yield* provider.list().pipe(Effect.orDie)
    const anthropic = yield* provider.get({ providerID: Provider.ID.make("anthropic") }).pipe(Effect.orDie)
    yield* Effect.logInfo("providers", {
      providers: providers.data.length,
      anthropic: anthropic.data.name,
    })
  }),
```

Transform của nhà cung cấp dùng để sửa cài đặt của nhà cung cấp và định nghĩa nguồn. Các lần đọc qua editor bao gồm
cả nhà cung cấp không hoạt động và trả về định nghĩa bất biến; `models.update` sửa một bản sao thuộc sở hữu của mô
hình nguồn.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.provider.transform((editor) => {
      editor.update("anthropic", (provider) => {
        provider.headers = { ...provider.headers, "x-company": "engineering" }
      })
      editor.models.update("anthropic", "claude-sonnet-4-5", (model) => (model.name = "Team Sonnet"))
      editor.models.remove("anthropic", "legacy-model")
      editor.remove("legacy-provider")
    })
  }),
```

Thay danh mục nguồn bằng `models.set`, rồi nạp lại sau khi các định nghĩa đã chụp thay đổi.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const source = { models: yield* loadModels() }
    yield* provider.transform((editor) => editor.models.set("acme", source.models))
    source.models = yield* loadModels()
    yield* provider.reload()
  }),
```

Để khám phá theo tài khoản, hãy truyền kết nối dùng để nạp danh mục đó làm `sourceConnection`. OpenCode loại trừ nhà
cung cấp ấy khi một kết nối khác đang được chọn, cho tới khi tiện ích mở rộng của bạn công bố danh mục đã làm mới.

```ts
const connection = yield * ctx.integration.connection.active("acme")
if (!connection) return
const inventory = yield * loadInventory(connection)
yield *
  ctx.provider.transform((editor) => {
    editor.add({ info: inventory.provider, models: inventory.models, sourceConnection: connection })
  })
```

Các schema: [`Provider.Info`](/api#schema-Provider.Info), [`Model.Info`](/api#schema-Model.Info).

```ts
interface ProviderRecord {
  readonly provider: Provider.Info
  readonly models: ReadonlyMap<string, Model.Info>
  readonly sourceConnection?: ConnectionInfo
}

interface ProviderEditor {
  list(): readonly ProviderRecord[]
  get(providerID: string): ProviderRecord | undefined
  add(input: { info: Provider.Info; models: readonly Model.Info[]; sourceConnection?: ConnectionInfo }): void
  update(providerID: string, update: (provider: Types.DeepMutable<Provider.Info>) => void): void
  remove(providerID: string): void
  readonly models: {
    set(providerID: string, models: readonly Model.Info[]): void
    update(providerID: string, modelID: string, update: (model: Types.DeepMutable<Model.Info>) => void): void
    remove(providerID: string, modelID: string): void
  }
}

interface ProviderDomain extends ProviderApi<unknown> {
  readonly transform: Transform<ProviderEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### Mô hình

Đọc các mô hình khả dụng và lựa chọn mặc định.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const model = ctx.model
    const models = yield* model.list().pipe(Effect.orDie)
    const selected = yield* model.default().pipe(Effect.orDie)
    yield* Effect.logInfo("models", { count: models.data.length, selected: selected.data?.name })
  }),
```

Transform của mô hình dùng để sửa toàn bộ tập ứng viên của các nhà cung cấp đang hoạt động. Các ứng viên đã tắt vẫn
sửa được cho đến khi mọi transform kết thúc; `update` chỉ có thể thêm một mô hình dưới một nhà cung cấp khả dụng.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.model.transform((editor) => {
      editor.list("anthropic").forEach((model) => {
        editor.update(model.providerID, model.id, (draft) => {
          draft.enabled = draft.capabilities.tools
        })
      })
      editor.default.set("anthropic", "claude-sonnet-4-5")
      editor.remove("anthropic", "legacy-model")
    })
  }),
```

Callback sửa các giá trị ghi đè thô của mô hình. Giá trị mặc định của nhà cung cấp được hợp nhất một lần khi OpenCode
chốt kết quả; các lần đọc không thay đổi sẽ dùng lại kết quả đó. `editor.provider` đọc định nghĩa nguồn bất biến, gồm
cả các template không hoạt động, chứ không phải kết quả của transform mô hình.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const model = ctx.model
    yield* model.transform((editor) => {
      const source = editor.provider.get("anthropic")?.models.get("claude-sonnet-4-5")
      if (!source) return
      editor.update("anthropic", source.id, (draft) => {
        draft.limit.context = Math.min(draft.limit.context, source.limit.context)
      })
    })
    yield* model.reload()
  }),
```

Schema: [`Model.Info`](/api#schema-Model.Info).

```ts
interface ModelEditor {
  list(providerID?: string): readonly Types.DeepMutable<Model.Info>[]
  get(providerID: string, modelID: string): Types.DeepMutable<Model.Info> | undefined
  update(providerID: string, modelID: string, update: (model: Types.DeepMutable<Model.Info>) => void): void
  remove(providerID: string, modelID: string): void
  readonly default: {
    get(): { providerID: string; modelID: string } | undefined
    set(providerID: string, modelID: string): void
  }
  readonly provider: {
    list(): readonly ProviderRecord[]
    get(providerID: string): ProviderRecord | undefined
  }
}

interface ModelDomain extends ModelApi<unknown> {
  readonly transform: Transform<ModelEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### Lệnh

Đọc các lệnh khả dụng tại vị trí hiện tại.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const command = ctx.command
    const commands = yield* command.list().pipe(Effect.orDie)
    yield* Effect.logInfo("commands", { names: commands.data.map((item) => item.name) })
  }),
```

Transform lệnh hiện tại chỉ cho phép thêm. Hàm thực thi nhận phiên, các tệp đính kèm của lời nhắc và chế độ phân
phối.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const command = ctx.command
    const session = ctx.session
    yield* command.transform((editor) => {
      editor.add({
        name: "security-review",
        description: "Review changes for security issues",
        execute: (input) =>
          session.prompt({
            ...input.prompt,
            sessionID: input.sessionID,
            text: `Review these changes for security issues.\n\n${input.prompt.text}`,
            delivery: input.delivery,
          }).pipe(Effect.asVoid),
      })
    })
    yield* command.reload()
  }),
```

Các schema: [`Command.Info`](/api#schema-Command.Info),
[`Session.Inbox.Delivery`](/api#schema-Session.Inbox.Delivery).

```ts
interface CommandInvocation {
  readonly sessionID: Session.ID

  readonly delivery: SessionInbox.Delivery
}

interface CommandDefinition {
  readonly name: string
  readonly description?: string
  readonly execute: (input: CommandInvocation) => Effect.Effect<void, unknown>
}

interface CommandEditor {
  add(definition: CommandDefinition): void
}

interface CommandDomain extends Pick<CommandApi<unknown>, "list"> {
  readonly transform: Transform<CommandEditor>

}
```

### Tích hợp

Đọc các tích hợp và phân giải thông tin xác thực đang hoạt động khi có.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    const integrations = yield* integration.list().pipe(Effect.orDie)
    const github = yield* integration.get({ integrationID: Integration.ID.make("github") }).pipe(Effect.orDie)
    const connection = yield* integration.connection.active("github")
    const credential = connection ? yield* integration.connection.resolve(connection).pipe(Effect.orDie) : undefined
    yield* Effect.logInfo("integration", {
      count: integrations.data.length,
      github: github.data.name,
      credential: credential?.type,
    })
  }),
```

Kết nối bằng khóa hoặc điều khiển một lần thử OAuth qua API đã kết nối.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    const token = yield* Config.Redacted("GITHUB_TOKEN").pipe(Effect.orDie)
    yield* integration.connect
      .key({ integrationID: Integration.ID.make("github"), key: Redacted.value(token) })
      .pipe(Effect.orDie)

    const attempt = yield* integration.oauth
      .connect({
        integrationID: Integration.ID.make("acme"),
        methodID: Integration.MethodID.make("oauth"),
      })
      .pipe(Effect.orDie)
    const status = yield* integration.oauth
      .status({
        integrationID: Integration.ID.make("acme"),
        attemptID: attempt.data.attemptID,
      })
      .pipe(Effect.orDie)
    yield* Effect.logInfo("OAuth status", { status: status.data })
  }),
```

Biến đổi các tích hợp và phương thức xác thực. Callback phương thức OAuth là Effect và có thể thu được tài nguyên có
phạm vi.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    yield* integration.transform((editor) => {
      editor.update("acme", (item) => (item.name = "Acme"))
      editor.method.update({
        integrationID: "acme",
        method: { id: "device", type: "oauth", label: "Sign in with Acme" },
        authorize: () =>
          Effect.succeed({
            mode: "code",
            url: "https://acme.example/device",
            instructions: "Enter the displayed code",
            callback: (code) => exchangeCode(code),
          }),
      })
    })
    yield* integration.reload()
  }),
```

Các schema: [`Integration.Info`](/api#schema-Integration.Info),
[`Integration.Method`](/api#schema-Integration.Method), [`Connection.Info`](/api#schema-Connection.Info),
[`Form.Answer`](/api#schema-Form.Answer).

```ts
type IntegrationOAuthAuthorization = {
  readonly url: string
  readonly instructions: string
  readonly expiresAt?: number
} & (
  | { readonly mode: "auto"; readonly callback: Effect.Effect<Credential.OAuth, unknown> }
  | { readonly mode: "code"; readonly callback: (code: string) => Effect.Effect<Credential.OAuth, unknown> }
)

type IntegrationOAuthMethodRegistration = {
  readonly integrationID: string
  readonly method: IntegrationOAuthMethod
  readonly authorize: (answer: Form.Answer) => Effect.Effect<IntegrationOAuthAuthorization, unknown, Scope.Scope>
  readonly refresh?: (credential: Credential.OAuth) => Effect.Effect<Credential.OAuth, unknown>
  readonly label?: (credential: Credential.OAuth) => string | undefined
}

interface IntegrationEditor {
  list(): readonly IntegrationRef[]
  get(id: string): IntegrationRef | undefined
  update(id: string, update: (integration: IntegrationRef) => void): void
  remove(id: string): void
  readonly method: {
    list(integrationID: string): readonly IntegrationMethod[]
    update(input: IntegrationMethodRegistration): void
    remove(integrationID: string, method: IntegrationMethod): void
  }
}

interface IntegrationDomain extends Omit<IntegrationApi<unknown>, "wellknown"> {
  readonly transform: Transform<IntegrationEditor>
  readonly reload: () => Effect.Effect<void>
  readonly connection: {
    readonly active: (integrationID: string) => Effect.Effect<ConnectionInfo | undefined>
    readonly resolve: (connection: ConnectionInfo) => Effect.Effect<Credential.Value | undefined, unknown>
  }
}
```

### MCP

Liệt kê các MCP server và trạng thái kết nối hiện tại của chúng.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const mcp = ctx.mcp
    const servers = yield* mcp.list().pipe(Effect.orDie)
    yield* Effect.logInfo("MCP servers", { count: servers.data.length })
  }),
```

Tiện ích mở rộng chỉ quản lý MCP server qua transform. Dùng `editor.set` để thêm hoặc thay thế một server,
`editor.update` để đổi cấu hình của nó và `editor.remove` để gỡ bỏ. Xem cấu hình bằng `editor.list` và `editor.get`.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const mcp = ctx.mcp
    yield* mcp.transform((editor) => {
      const servers = editor.list()
      const docs = editor.get("docs")
      editor.set("docs", { type: "remote", url: "https://mcp.example.com" })
```

và cho phép OpenCode kết nối. OpenCode đối chiếu vòng đời của server dựa trên cấu hình đã qua transform.

### Công cụ

Đăng ký công cụ có kiểu với Effect `Schema`. Hàm thực thi nhận đầu vào đã giải mã và trả về một Effect chứa đầu ra có
kiểu, nội dung hiển thị hoặc siêu dữ liệu.

Editor hỗ trợ `add`, `update` và `remove`. Callback của transform là đồng bộ: nó không được trả về Effect hay
Promise. Hãy nạp dữ liệu bên ngoài trước khi đăng ký hoặc nạp lại. OpenCode phát lại các transform đang hoạt động
theo thứ tự đăng ký trên một editor mới; với cùng một tên công cụ hiệu lực, một đăng ký hợp lệ sau đó sẽ ghi đè đăng ký
trước đó.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.transform((editor) => {
      editor.namespace({
        name: "acme",
        description: "Customer account tools",
      })
      editor.add({
        name: "greeting",
        description: "Create a greeting",
        input: Schema.Struct({ name: Schema.String }),
        output: Schema.Struct({ greeting: Schema.String }),
        options: { namespace: "acme", codemode: true },
        execute: ({ name }, context) =>
          Effect.gen(function* () {
            yield* context.progress({ status: "greeting" })
            return { output: { greeting: `Hello ${name}!` } }
          }),
      })
    })
  }),
```

Gọi `yield* ctx.tool.reload()` sau khi dữ liệu nguồn được callback chụp thay đổi. Việc nạp lại phát lại các transform
đang hoạt động mà không đổi thứ tự của chúng; nó không chạy lại effect của tiện ích mở rộng.

Mỗi công cụ có một `id` chứa tên hiệu lực, và `get()` trả về `undefined` khi ID đó không tồn tại. Hãy dùng `update`
và `remove` với tên hiệu lực của công cụ, gồm cả namespace của nó (`acme_greeting` ở trên). Dấu chấm trong namespace và
ký tự không được hỗ trợ trong tên công cụ sẽ trở thành `_`. Tên không tồn tại sẽ bị bỏ qua; để tạo một công cụ cần
dùng `add` với định nghĩa đầy đủ. Cập nhật giữ nguyên tên và namespace. Hãy gán schema hoặc tùy chọn mới để thay thế
thay vì thay đổi các giá trị lồng nhau. Cập nhật không hợp lệ sẽ được ghi log và giữ nguyên định nghĩa trước đó.

```ts
yield *
  ctx.tool.transform((editor) => {
    editor.update("acme_greeting", (tool) => {
      tool.description = "Greet the user by name"
    })
    editor.remove("acme_obsolete")
  })
```

Các cập nhật và lần gỡ bỏ được phát lại đúng thứ tự cùng với các lần thêm, kể cả sau khi danh mục MCP được làm mới.

`transform` trả về một registration có phạm vi. Hãy chạy `yield* registration.dispose` để xóa transform của nó và dựng
lại từ các transform còn lại, làm lộ ra định nghĩa trước đó mà nó đã ghi đè. Việc giải phóng có tính lũy thừa bằng,
và việc đóng scope của tiện ích mở rộng cũng giải phóng các registration của nó.

Mỗi yêu cầu mô hình đều chụp một ảnh công cụ. Việc nạp lại và giải phóng chỉ ảnh hưởng tới những ảnh chụp tương lai,
không ảnh hưởng tới các định nghĩa hay hàm thực thi đã được một yêu cầu đang tồn tại chụp. Hàm thực thi đóng trên dữ
liệu tiện ích mở rộng có thể thay đổi vẫn nhìn thấy dữ liệu đó; hãy chụp một giá trị bên trong transform khi giá trị
đó phải gắn với định nghĩa ấy.

Các schema: [`Tool.Content`](/api#schema-Tool.Content), [`Tool.TextContent`](/api#schema-Tool.TextContent),
[`Tool.FileContent`](/api#schema-Tool.FileContent).

```ts

  list(): readonly (Tool.Info & { readonly id: string })[]

  namespace(namespace: { name: string; description: string }): void
  add<Input extends Tool.ValueSchema<any>, Output extends Tool.ValueSchema<any> | undefined>(

  ): void
  update(id: string, update: (tool: Types.Mutable<Tool.Info>) => void): void
```

### VCS

Đọc thông tin repository, trạng thái bản làm việc hoặc chênh lệch tệp.

```ts
effect: (ctx) =>

    const info = yield* vcs.get().pipe(Effect.orDie)
    const branches = yield* vcs.branches({ search: "feature", limit: 10 }).pipe(Effect.orDie)
    const changes = yield* vcs.status().pipe(Effect.orDie)
```

Đăng ký một nhà cung cấp có phạm vi theo vị trí thông qua một transform có phạm vi. Nhà cung cấp khớp với loại
repository được phát hiện sẽ được chọn tự động; hãy dùng `editor.default.set` để chọn nhà cung cấp khác.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const vcs = ctx.vcs
    yield* vcs.transform((editor) => {
      editor.add({
        id: "custom",
        name: "Custom VCS",

        branches: (input) => readBranches(input),
        status: (scope) => readStatus(scope.worktree),
        diff: (input) => readDiff(input),
      })
      editor.default.set("custom")
    })
  }),
```

Callback của nhà cung cấp nhận vị trí hiện tại, thư mục gốc của bản làm việc, thư mục gốc chuẩn của dự án và kho
repository tùy chọn. Callback diff còn nhận chế độ đã chọn, số dòng ngữ cảnh được yêu cầu và ngân sách byte đầu ra.
Việc phát hiện repository vẫn dùng các bộ dò Git và Mercurial tích hợp sẵn của OpenCode.

Nhà cung cấp có thể tùy chọn hiện thực `init(scope)` để tạo một repository trong `scope.worktree`. Quá trình khởi tạo
chọn nhà cung cấp theo ID (Git theo mặc định), không phải theo loại repository được phát hiện. Hãy đăng ký một nhà
cung cấp có `init` ngay cả khi vị trí chưa có repository; OpenCode kiểm tra rằng thư mục tồn tại và chưa có repository
trước khi gọi nó, rồi phát hiện lại dự án. Các định dạng repository mới vẫn cần được hỗ trợ phát hiện ngoài callback
này.


### Phiên

Sửa các chỉ thị hệ thống, tin nhắn hoặc công cụ đã lắp ráp ngay trước khi gửi tới mô hình. `context` chạy cho vòng
lặp tác nhân; `compaction`, `generate` và `title` chạy cho các yêu cầu phụ trợ đó. `compaction` và `title` chấp nhận
một `result` để bỏ qua lệnh gọi mô hình.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("context", (event) =>
      Effect.sync(() => {
        event.system.push({ type: "text", text: "Keep the review focused on correctness." })
        delete event.tools.write
      }),
    )
    yield* session.hook("compaction", (event) =>
      Effect.map(summarize(event.messages), (summary) => {
        event.result = { summary }
      }),
    )
  }),
```

Sửa cài đặt của yêu cầu mô hình và tùy chọn giới hạn móc nối cho một nhà cung cấp. Sự kiện mang cùng `kind` như các
móc nối HTTP bên dưới.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook(
      "model.request",
      (event) => Effect.sync(() => (event.headers["x-plugin"] = "review")),
      { providerID: "anthropic" },
    )
  }),
```

Sửa yêu cầu hoặc phản hồi gốc của nhà cung cấp. Body của chúng là luồng chỉ đọc một lần; hãy sao chép hoặc thay
thế body trước khi đọc. Cả hai móc nối đều chạy cho mọi yêu cầu mà một phiên phát ra; `event.kind` là `"primary"`,
`"compaction"`, `"title"` hoặc `"generate"` tùy theo luồng nào đã phát yêu cầu.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("http.request", (event) =>
      Effect.sync(() => {
        event.request.headers.set("x-session-id", event.sessionID)
        if (event.kind === "title") event.request.headers.set("x-priority", "background")
      }),
    )
    yield* session.hook("http.response", (event) =>
      Effect.sync(() => {
        event.response = new Response(event.response.body, {
          status: event.response.status,
          headers: { ...Object.fromEntries(event.response.headers), "x-plugin": "review" },
        })
      }),
    )
  }),
```

Các nhà cung cấp truyền dữ liệu qua WebSocket sẽ dùng lại một kết nối cho mỗi phiên, nên các móc nối HTTP không
bao giờ thấy lưu lượng đó. Móc nối thử nghiệm `experimental.ws.handshake` chạy một lần cho mỗi lệnh gọi mô hình
trước khi kết nối được chọn và đưa ra `url` cùng `headers` của kết nối; thay đổi một trong hai sẽ mở lại socket. Các
móc nối HTTP vẫn chạy cho mọi yêu cầu mà một route WebSocket chuyển sang.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook(
      "experimental.ws.handshake",
      (event) =>
        Effect.gen(function* () {
          event.headers.authorization = `Bearer ${yield* mintToken(event.url)}`
          delete event.headers["api-key"]
        }),
      { providerID: "azure" },
    )
  }),
```

`experimental.ws.send` và `experimental.ws.receive` đưa ra chính các frame đó: `send` chạy sau khi driver của nhà
cung cấp dựng khung gửi đi, `receive` chạy với mỗi khung đến trước khi driver quan sát nó. Đúng nội dung mà `frame`
chứa khi móc nối kết thúc là thứ được gửi đi hoặc tới driver; OpenCode không kiểm tra nó.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook(
      "experimental.ws.send",
      (event) =>
        Effect.sync(() => {
          const body = JSON.parse(event.frame)
          if (body.type === "response.create") body.metadata = { ...body.metadata, session: event.sessionID }
          event.frame = JSON.stringify(body)
        }),
      { providerID: "openai" },
    )
  }),
```

Ghi đè quyết định thử lại cho một lỗi của nhà cung cấp hoặc thay độ trễ của nó tính bằng mili giây. Móc nối chạy sau
khi OpenCode phân loại lỗi và đề xuất chính sách của mình, nhưng trước khi bất kỳ lần thử lại nào được lên lịch. Nó
không tiết lộ cách OpenCode thực hiện lần thử tiếp theo bên trong.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook("retry", (event) =>
      Effect.sync(() => {
        if (event.error.status === 429) {
          event.decision = { retry: true, delay: 10_000 }
          return
        }
        if (event.error.type === "provider.invalid-request" && event.attempt === 2) {
          event.decision = { retry: true, delay: 0 }
          return
        }
        if (event.attempt >= 3) event.decision = { retry: false }
      }),
    )
  }),
```

`decision` ban đầu là chính sách của OpenCode, nên các móc nối có thể biến một lỗi nhà cung cấp vốn kết thúc thành có
thể thử lại hoặc phủ quyết một lần thử lại được đề xuất. Nhiều móc nối chạy theo thứ tự đăng ký và các móc nối sau
thấy quyết định hiện tại. Số lần thử tối đa tích hợp sẵn vẫn là giới hạn tuyệt đối. `attempt` là lần thử thực tế
đang được đề xuất; yêu cầu ban đầu là lần thử `1`, nên lần thử lại đầu tiên là lần thử `2`. Các độ trễ không hợp lệ
(`NaN`, vô cùng hoặc giá trị âm) sẽ quay về độ trễ đã tính. Cơ chế khôi phục khi ngữ cảnh tràn vẫn tách biệt vì nó
nén hội thoại thay vì thử lại cùng một yêu cầu.

#### Tham chiếu

```ts
interface SessionHooks {
  readonly context: SessionContext
  readonly compaction: SessionCompaction
  readonly generate: SessionGenerate
  readonly title: SessionTitle
  readonly "model.request": SessionModelRequest
  readonly "http.request": SessionHttpRequest
  readonly "http.response": SessionHttpResponse
  readonly "experimental.ws.handshake": SessionWebSocketHandshake
  readonly "experimental.ws.send": SessionWebSocketSend
  readonly "experimental.ws.receive": SessionWebSocketReceive
  readonly retry: SessionRetry
}

type RetryDecision = { retry: false } | { retry: true; delay: number }

interface SessionRetry {
  readonly sessionID: string
  readonly agent: string
  readonly model: { providerID: string; id: string; variant?: string }
  readonly error: { type: string; message: string; status?: number }
  readonly attempt: number
  decision: RetryDecision
}

interface SessionHookDomain {
  readonly hook: ModelHooks<SessionHooks>
}
```

### Shell

Sửa lệnh shell, thư mục làm việc, thời gian chờ, tệp thực thi hoặc biến môi trường trước khi chạy.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const shell = ctx.shell
    yield* shell.hook("create.before", (event) =>
      Effect.sync(() => {
        if (event.command === "npm") event.command = "bun"
        event.timeout = Math.min(event.timeout, 60_000)
        event.env.COMPANY_ENV = "development"
      }),
    )
  }),
```

#### Tham chiếu

```ts
interface ShellCreateBefore {
  command: string
  cwd: string
  timeout: number
  shell: string
  env: Record<string, string | undefined>
}

interface ShellHooks {
  readonly "create.before": ShellCreateBefore
}

interface ShellHookDomain {
  readonly hook: Hooks<ShellHooks>
}
```

### Công cụ

Các móc nối trước có thể thay thế đầu vào hoặc thất bại bằng `Tool.Error`.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.hook("execute.before", (event) =>
      event.tool === "write"
        ? Effect.fail(new Tool.Error({ message: "Writes are disabled" }))
        : Effect.logDebug("tool input", { tool: event.tool, input: event.input }),
    )
  }),
```

Các móc nối sau có thể xem hoặc thay thế kết quả thành công và lỗi.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.hook("execute.after", (event) => {
      if (event.status === "error") return Effect.logWarning("tool failed", { message: event.error.message })
      return Effect.sync(() => {
        event.result = { ...event.result, metadata: { observed: true } }
      })
    })
  }),
```

#### Tham chiếu

```ts
interface ToolHooks {
  readonly "execute.before": ToolExecuteBefore
  readonly "execute.after": ToolExecuteAfter
}

interface ToolFailures extends Record<keyof ToolHooks, unknown> {
  readonly "execute.before": Tool.Error
  readonly "execute.after": never
}

interface ToolHookDomain {
  readonly hook: Hooks<ToolHooks, ToolFailures>
}
```

Các kiểu đăng ký dùng chung cho biết thao tác nào cần scope của tiện ích mở rộng.

```ts
interface Registration {
  readonly dispose: Effect.Effect<void>
}

type Hooks<Spec, Failures extends Record<keyof Spec, unknown> = Record<keyof Spec, never>> = <Name extends keyof Spec>(
  name: Name,
  callback: (input: Spec[Name]) => Effect.Effect<void, Failures[Name]>,
) => Effect.Effect<Registration, never, Scope.Scope>

type Transform<Input> = (callback: (input: Input) => void) => Effect.Effect<Registration, never, Scope.Scope>
```

## Xuất bản

Một tiện ích mở rộng dạng package dùng cùng kiểu export mặc định với tiện ích mở rộng Effect cục bộ. Hãy export phần
triển khai Effect từ entrypoint chính và khai báo `effect` là một `peerDependency`.

```json title="package.json"
{
  "name": "opencode-acme-effect-plugin",
  "version": "1.0.0",
  "type": "module",
  "exports": {
    ".": "./src/index.ts"
  },
  "dependencies": {
    "@opencode/plugin": "latest"
  },
  "peerDependencies": {
    "effect": "^4.0.0"
  }
}
```

OpenCode chuyển hướng các import của `effect`, các subpath `effect/*` được export và `@opencode/plugin` (bao gồm cả
import từ các phụ thuộc trong `node_modules` của tiện ích mở rộng) về các thực thể runtime của host, để fiber, logger
và bộ phân tích `Schema` dùng chung một bản runtime.

- Không đóng gói `effect` vào artifact của tiện ích mở rộng đã xuất bản. Nếu bạn build bằng bundler, hãy đánh dấu
  `effect` và `effect/*` là external.
- Tiện ích mở rộng và các phụ thuộc `node_modules` của chúng luôn chạy với thực thể `effect` của bản phát hành OpenCode
  đang host. Hãy dùng các API và đường dẫn module của `effect` tương thích với bản phát hành OpenCode mà bạn nhắm tới;
  các phụ thuộc được xây trên một major khác của `effect` (chẳng hạn Effect 3) cũng nhận `effect` của host và không được
  hỗ trợ.
- Chỉ các subpath `effect` công khai được cung cấp. Một tiện ích mở rộng import một module `internal` riêng tư của
  Effect sẽ không nạp được và báo lỗi nêu đường dẫn đó.
- File nhị phân OpenCode đã biên dịch không chứa asset Scalar và Swagger UI dùng cho các trang tài liệu HTTP API của
  Effect; phục vụ những trang đó từ một tiện ích mở rộng sẽ hiển thị một thông báo thay thế.

Entrypoint của package export `Plugin.define` cùng một hàm `effect`.

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "acme.published",
  effect: (ctx) =>
    Effect.gen(function* () {
      const storage = ctx.storage
      yield* storage.set("installed", true)
    }),
})
```

Hãy dùng các phiên bản tương thích với bản phát hành OpenCode mà bạn nhắm tới và hãy thử trên package đã cài, thay vì
chỉ bản sao liên kết trong không gian làm việc.

```sh
bun pm pack
bun add ./opencode-acme-effect-plugin-1.0.0.tgz
```
