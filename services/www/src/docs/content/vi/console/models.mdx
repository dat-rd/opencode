OpenCode Console cung cấp danh sách các mô hình đã được đội ngũ OpenCode kiểm thử và xác minh. Hãy đăng nhập, thêm tín dụng
và nhận API key để dùng chúng với OpenCode hoặc một tác nhân lập trình mã khác.

Console hoạt động giống như mọi nhà cung cấp khác trong OpenCode. Đây là **hoàn toàn tùy chọn**, và bạn có thể dùng một
nhà cung cấp khác thay thế. Để biết gói đăng ký có mức sử dụng bao gồm, xem [OpenCode Go](/console/go).

## Cách hoạt động

1. Đăng nhập vào [console](https://opencode.ai/console), thêm thông tin thanh toán và tín dụng, rồi sao chép API key của bạn.
2. Chạy `/connect` trong TUI, chọn nhà cung cấp trả theo mức dùng của OpenCode và dán API key của bạn.

   ```text
   /connect
   ```

3. Chạy `/models` để xem các mô hình khả dụng và chọn một mô hình.

   ```text
   /models
   ```

Bạn bị tính phí theo từng request và có thể thêm tín dụng vào tài khoản của mình.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "model": "opencode/gpt-5.5",
}
```

Lấy danh sách đầy đủ các mô hình khả dụng và metadata của chúng từ endpoint mô hình:

```bash
curl https://opencode.ai/inference/v1/models
```

### Jev

Jev là một mô hình System One của TypeSafe AI dành cho các quyết định nhanh và có cấu trúc. Thay vì tạo văn bản, nó đánh
giá một `state` theo các câu hỏi có kiểu và trả về giá trị cùng xác suất mà mã của bạn có thể dùng trực tiếp. Nó hỗ trợ
câu hỏi có/không (`noul`), chọn một (`choice`) và chấm điểm theo tiêu chí (`score`).

Hãy dùng OpenCode Console API key của bạn với endpoint
`https://opencode.ai/inference/systemone/v1/systemone`. Ví dụ này kiểm tra xem một yêu cầu hỗ trợ có khẩn cấp hay
không:

```bash
curl https://opencode.ai/inference/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

Bạn có thể đặt nhiều câu hỏi trong một request. Jev đánh giá chúng song song và trả về từng câu trả lời dưới ID câu
hỏi tương ứng:

```bash
curl https://opencode.ai/inference/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

Hãy dùng `jev-1.13-free` thay cho `jev-1.13` để dùng mô hình miễn phí có thời hạn. Xem [tài liệu TypeSafe
AI](https://docs.typesafe.ai/) để biết chi tiết về các loại câu hỏi và trường phản hồi.

## Bối cảnh

Có rất nhiều mô hình, nhưng chỉ một vài mô hình hoạt động tốt với vai trò tác nhân lập trình mã. Cấu hình, hiệu năng và
chất lượng cũng khác nhau giữa các nhà cung cấp, nên một mô hình được truy cập qua một gateway như OpenRouter có thể
hoạt động khác.

<Callout type="tip">Chúng tôi đã kiểm thử một nhóm mô hình và nhà cung cấp được chọn, hoạt động tốt với OpenCode.</Callout>

Để xây dựng danh mục này, chúng tôi đã:

1. Kiểm thử một nhóm mô hình được chọn và trao đổi với đội ngũ của họ về cách vận hành tốt nhất.
2. Phối hợp với các nhà cung cấp để đảm bảo các mô hình được phục vụ đúng cách.
3. Đo hiệu năng từng cặp mô hình/nhà cung cấp để đưa ra một danh sách mà chúng tôi thấy đáng để giới thiệu.

Console là một AI gateway giúp bạn truy cập các mô hình này.

## Mục tiêu

Chúng tôi xây dựng Console để:

1. **Đo hiệu năng** các mô hình và nhà cung cấp tốt nhất cho tác nhân lập trình mã.
2. Cung cấp lựa chọn **chất lượng cao nhất** mà không hạ hiệu năng hay chuyển tuyến sang nhà cung cấp rẻ hơn.
3. Chuyển tới bạn **mức giảm giá** bằng cách bán theo chi phí, chỉ cộng thêm phần nhỏ để bù chi phí xử lý.
