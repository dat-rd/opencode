---
title: "Phím tắt"
---

Tùy chỉnh các phím tắt trong `cli.json`:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Dùng một chuỗi cho một phím:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Phân tách các phương án bằng dấu phẩy:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Tắt một phím tắt bằng `"none"` hoặc `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Dùng một đối tượng để định nghĩa hành vi của sự kiện:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` mặc định là `ctrl+x`. `<leader>` trong một phím tắt khác chỉ tới phím đó.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Các ID lệnh không hợp lệ sẽ bị từ chối.

## Mini

Lệnh `app.clear` chỉ hoạt động trong [`opencode mini`](/cli). Nhấn `ctrl+l` để xóa màn hình đang hiển thị và vẽ lại lời nhắc. Terminal vẫn giữ lịch sử cuộn.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| ----------- | -------- | ------------ |
| `app.clear` | `ctrl+l` | Xóa màn hình |

## Trình xem diff

Nhấn `d` (`diff.switch_source`) để chọn **Tất cả**, **Đã commit**, **Chưa commit** hoặc **Lượt cuối** (bên trong một phiên), hoặc chọn **Gốc** để đổi nhánh so sánh. Lựa chọn được ghi nhớ cho tới khi TUI thoát ra. Đặt phạm vi ban đầu bằng [`diffs.source` trong `cli.json`](/cli/config#diffs).

Các phím cuộn, chuyển trang và về đầu/cuối luôn điều khiển diff. Không có phím chuyển tiêu điểm bàn phím: nhấp vào tệp để mở, nhấp vào thư mục để mở rộng hoặc thu gọn, và dùng con lăn chuột để cuộn cây tệp.

Dùng `n` / `p` hoặc `alt+down` / `alt+up` (Option trên macOS) để chuyển giữa các tệp. Bên trong trình xem diff, các phím tắt Alt điều hướng giữa các tệp chứ không phải các tab phiên.

Nhấn `m` để đánh dấu một tệp là đã xem xét và thu gọn phần thân patch của nó. Ở chế độ xem tất cả tệp, nhấn `m` lần nữa để bỏ đánh dấu và mở lại patch. Chế độ xem một tệp tự động chuyển sang tệp tiếp theo khi đánh dấu đã xem xét, nhưng dừng ở tệp cuối cùng thay vì quay vòng. Bỏ đánh dấu một tệp không bao giờ chuyển tệp.

Nhấp chuột phải vào một tệp trong thanh bên hoặc vào tiêu đề diff của nó để chọn **Đánh dấu hoàn thành** (hoặc **Đánh dấu chưa hoàn thành**). Điều này thay đổi cùng trạng thái đã xem xét như `m`. Đánh dấu hoàn thành một tệp khác từ menu của nó sẽ không chọn tệp đó cũng không chuyển khỏi tệp đang đọc.

Các phương án có phím Shift của `diff.help` hỗ trợ những terminal báo cáo phím bổ trợ Shift khi bạn nhấn `?`.

| `composer.shell.kill`         | `ctrl+d` | Dừng lệnh shell       |

Chọn một lệnh đang chạy trong tab **Shell** và nhấn **Enter**, hoặc nhấp vào lệnh đó, để xem stdout và stderr đã thu thập. Dùng **↑/↓**, **Page Up/Down** hoặc **Home** để cuộn, **End** để theo dõi kết quả mới, và **Esc** để quay lại mà không dừng lệnh. Trình xem hiển thị kết quả gần đây và vẫn mở sau khi lệnh kết thúc; kết quả được chuyển hướng tới một tệp sẽ không có trong đó.
